# 🧠 BiLSTM Sentiment Analyser

A **Bidirectional LSTM** (BiLSTM) neural network built with **PyTorch** and served
as an interactive web application with **Streamlit**.

The model classifies any input text as **Positive**, **Neutral**, or **Negative**.

---

## 📁 Project Structure

```
bilstm_sentiment/
├── app.py            # Streamlit web application (UI + inference)
├── train.py          # Model training script
├── model.py          # BiLSTM neural network architecture
├── utils.py          # Tokenisation, vocabulary, dataset utilities
├── dataset.csv       # Example labelled dataset (text, label)
├── requirements.txt  # Python dependencies
└── README.md         # This file
```

After training, one additional file is created:

```
bilstm_model.pth      # Saved model checkpoint (generated by train.py)
```

## ⚙️ Installation

### Prerequisites

- Python 3.9 or higher
- pip

### Steps

```bash
# 1. Clone or download the project
git clone https://github.com/your-username/bilstm-sentiment.git
cd bilstm-sentiment

# 2. (Recommended) Create a virtual environment
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows

# 3. Install dependencies
pip install -r requirements.txt
```

NLTK data (punkt tokeniser, stopwords, wordnet) is downloaded automatically
the first time `utils.py` is imported.

## 🏋️ Training the Model

```bash
python train.py
```

What this does:

1. Reads `dataset.csv` (columns: `text`, `label`)
2. Tokenises each row with NLTK
3. Builds a vocabulary from all tokens
4. Splits data into train / validation sets (85 % / 15 %)
5. Trains the BiLSTM model for up to 30 epochs
6. Saves the best checkpoint (by validation accuracy) as **`bilstm_model.pth`**

Training output looks like:

```
[INFO] Using device: cpu
[INFO] Loading dataset from 'dataset.csv' …
[INFO] 40 samples
[INFO] Vocabulary size: 312
Epoch [01/30] Train Loss: 1.0842  Acc: 0.3750 | Val Loss: 1.0711  Acc: 0.5000 | Time: 0.3s
  ✓ Saved new best checkpoint (val_acc=0.5000)
...
[DONE] Training complete. Best validation accuracy: 0.8333
[DONE] Model checkpoint saved to 'bilstm_model.pth'
```

### Custom dataset

Replace `dataset.csv` with any CSV that has two columns:

| text | label |
|------|-------|
| I love this! | positive |
| It's okay. | neutral |
| Terrible quality. | negative |

Supported label values: `positive`, `neutral`, `negative`

## 🖥️ Running Locally

Make sure `bilstm_model.pth` exists (run training first), then:

```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501**

## 🌐 Deploying on Render

### 1. Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/your-username/bilstm-sentiment.git
git push -u origin main
```

> **Important:** Either commit `bilstm_model.pth` to the repo, or add a
> build step that runs `python train.py` before the app starts (see below).

### 2. Create a New Web Service on Render

1. Go to [https://render.com](https://render.com) → **New → Web Service**
2. Connect your GitHub repository
3. Fill in the settings:

| Setting | Value |
|---------|-------|
| **Environment** | Python 3 |
| **Build Command** | `pip install -r requirements.txt && python train.py` |
| **Start Command** | `streamlit run app.py --server.port 10000 --server.address 0.0.0.0` |

4. Click **Create Web Service**

Render will install dependencies, train the model, and then start the
Streamlit app on port 10000.

### Start command (exact)

```bash
streamlit run app.py --server.port 10000 --server.address 0.0.0.0
```

### Environment variables (optional)

No environment variables are required for the default setup.

## 🏗️ Architecture

```
Input Text
    │
    ▼
NLTK Tokenisation + Lemmatisation + Stop-word removal
    │
    ▼
Vocabulary Lookup  →  Integer Sequence  →  Padding to MAX_LEN=64
    │
    ▼
Embedding Layer  (vocab_size × 128)
    │
    ▼
Dropout (0.4)
    │
    ▼
BiLSTM  (128 → 256 hidden, 2 layers, bidirectional)
    │
    ▼  concat(forward_h, backward_h)  →  512-dim vector
    │
    ▼
Dropout (0.4)
    │
    ▼
Linear (512 → 3)
    │
    ▼
Softmax  →  Positive | Neutral | Negative
```
